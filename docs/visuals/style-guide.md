# Project visual style

Scope: README cover, output preview, and workflow illustration. These are documentation assets, not a product UI.

- Paper: `#f7f7f5`
- Ink: `#202124`
- Muted: `#62656b`
- Rules: `#d7d7d3`
- Accent: `#e11d48` (matches the skill's existing agent metadata)
- Accent tint: `#fff1f4`
- Titles: Georgia / serif; labels: Arial / PingFang SC / sans-serif; technical values: SFMono-Regular / Consolas / monospace.
- Flat surfaces, thin borders, no shadows. Use accent on at most two workflow nodes.
- Designed previews are labeled and never presented as screenshots of an agent application.
- HTML/SVG sources are editable; PNG images are the portable README display format.
